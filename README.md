# Books Data Exploratory Data Analysis (EDA)

## 📌 Overview

This project performs basic Exploratory Data Analysis (EDA) on a books dataset to understand the data and discover meaningful patterns and insights.

The analysis is performed using Python and popular data analysis libraries.
